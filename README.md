# 微信聊天文件防撤回工具

## 目标

在微信聊天中,即使对方撤回已发送的文件,仍然可以保留文件。

## 前提与假设

- 开启微信的文件自动下载,使微信在收到文件时自动下载到本地。
- 电脑版微信将文件保存在形如 `\xwechat_files\<user_name>\msg\file\2026-10` 的路径下,其中 `user_name` 为微信账号对应的目录名,`2026-10` 为按月份划分的子目录。
- 微信允许撤回的时限约为 2 分钟,备份必须在这一时间窗口内完成。

## 电脑版微信的文件撤回机制

在电脑版微信中,微信会将收到的文件下载到上述存储路径。

发送方撤回文件时,微信会在对应的文件路径下删除该文件。

因此,如果能在微信完成文件保存后即刻将文件复制到另一文件路径,即使文件被撤回,微信也无法删除复制的副本。

## 现有工具分析
现有具备目标功能的工具主要有以下几类：

1. 微信防撤回脚本:大多通过修改 dll 文件等方式实现。此类方案修改了微信程序本体,且微信版本变动后需要重新适配。
2. 文件保护系统:功能覆盖面更广,但需要占用较多的处理器资源和内存空间,对本目标而言过重且繁琐,安装、配置也较为复杂。
3. 网盘备份:确实可以保住被撤回的文件,但备份范围是整个目录,空间占用与隐私暴露面都更大；备份的触发周期通常也远长于2分钟的撤回时限,需要高频备份才能可靠生效。

以上方案要么侵入微信本体,要么在资源占用与备份范围上不够克制,因此考虑实现一个更轻量的专用工具。

## 目标工具原理
1. 创建一个负责将文件从微信存储文件夹复制到备份文件夹的进程。该进程在正常情况下处于挂起状态,不占用处理器资源。
2. 当微信存储文件夹出现文件写入时,由内核将该进程唤醒并调入处理器,进程随即把新文件复制到备份文件夹,同时维护一个计时器。
3. 若在允许撤回时限过去后原文件依然存在,则删除备份文件夹中对应的备份文件,避免占用过大硬盘空间。

## 限制
1. 目前阶段仅考虑在Windows系统。
2. 无法确保大文件的防撤回。若在大文件发送方上传或接收方下载过程中,发送方进行撤回,本机无法接收到完整文件,则无法实现防撤回功能,这是传输过程限制的
3. 仅覆盖文件。图片、视频、语音等储存在其他文件路径,不在监控范围内
4. 依赖微信当前的路径结构和"撤回即删本地文件"的行为。若在微信更新中改动了两者的任意一项,则本工具将失效
